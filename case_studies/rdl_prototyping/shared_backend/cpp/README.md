# C++ RDL Backend

This directory contains the paper-grade shared backend for the RDL
adapter-generation case study. It is the backend that
`scripts/run_llm_trial.py` invokes when grading LLM-generated adapters.

The Python implementation at `../rdl_backend.py` remains the executable
reference specification. Any semantic change must keep the Python and C++
implementations in lock-step and must pass the synthetic self-test suite.

## Scope

The backend intentionally implements the P0 fragment only:

- conjunction-only QF_RDL,
- constraints of the form `lhs - rhs <= bound` or `lhs - rhs < bound`,
- unary bounds represented through the distinguished `ZERO` variable,
- exact rational bounds via GMP `mpq_class`,
- strict inequalities represented symbolically as `(value, strict)`.

It does not implement Boolean RDL (`or`, `not`, `=>`, `ite`) and does not
call any SMT solver. It decides satisfiability by detecting negative
cycles in the difference-constraint graph using Floyd-Warshall.

## Build

From this directory:

```bash
bash build.sh
```

The script configures CMake, builds the executable, and runs the unit
tests:

```text
build/rdl_backend
build/unit_bound
build/unit_solver
```

Dependencies:

- CMake >= 3.16
- C++17 compiler
- GMP C++ bindings (`libgmp-dev` on Debian/Ubuntu)

## CLI

```bash
build/rdl_backend path/to/rdl_atoms.json
```

The program prints exactly one verdict on stdout:

```text
sat
unsat
unknown
```

Malformed payloads or unsupported modes print a diagnostic to stderr and
return `unknown`, matching the Python reference behavior.

## Self-Test

The repository includes a 100-instance synthetic conjunction-only test
set generated by construction:

```bash
python3 ../../scripts/gen_synth_rdl.py --force
python3 ../../scripts/test_backend.py --quiet
```

`test_backend.py` requires three-way agreement:

- generated `.expect` label,
- Python reference backend,
- C++ backend binary.

The expected passing summary is:

```text
three-way self-test summary: 100/100 passed (sat=51, unsat=49)
```

## File Map

- `include/rdl_bound.hpp`: symbolic strict bound `(mpq_class value, bool strict)`.
- `include/rdl_payload.hpp`: in-memory `rdl_atoms.json` payload representation.
- `include/rdl_solver.hpp`: public `decide(payload)` API.
- `src/rdl_bound.cpp`: infinity sentinel.
- `src/rdl_payload.cpp`: small dependency-free JSON loader and rational parser.
- `src/rdl_solver.cpp`: graph construction and Floyd-Warshall negative-cycle check.
- `src/rdl_backend.cpp`: CLI entry point.
- `tests/unit_bound.cpp`: arithmetic and ordering checks.
- `tests/unit_solver.cpp`: satisfiability/unsatisfiability regression checks.
